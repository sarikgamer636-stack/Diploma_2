Проверяются только ручки из задания: создание пользователя, логин и создание заказа.

Создание пользователя:
- можно создать уникального пользователя
- нельзя создать пользователя, который уже зарегистрирован
- нельзя создать пользователя, если не передано одно из обязательных полей

Логин:
- можно войти под существующим пользователем
- нельзя войти с неверным паролем

Создание заказа:
- заказ с авторизацией и ингредиентами
- заказ без авторизации
- заказ без ингредиентов
- заказ с неверным хешем ингредиента
